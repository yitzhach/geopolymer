# Geopolymer Platform

A platform connecting geopolymer and alkali-activated-material knowledge, materials, experimentation and expert services.

**Learn → Formulate → Buy → Test → Ask → Share**

## Current state

Business and website planning baseline. No application or production storefront yet. Brand, suppliers, product prices and shipping scope remain provisional.

Start with [HANDOFF.md](HANDOFF.md). This repository is the working source of truth; keep its documents current as decisions and implementation progress.

## Working principles

Preserve source citations. Separate verified information, assumptions and recommendations. Do not describe proposed products as available or literature formulations as independently validated. Update HANDOFF.md and DECISIONS.md when work changes direction.
