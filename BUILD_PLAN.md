# Build plan — first prototype

24 September 2026. Owner requested GitHub publication followed by building.
This plan translates the existing architecture into a small reviewable first build.
Technical stack and hosting are not selected yet.

## First build scope

Use the temporary title “Geopolymer Platform”; keep brand tokens easy to replace.
Build a responsive homepage, material index/detail, research index/detail,
formulation detail and kit/product detail. Demonstrate one coherent journey:
metakaolin → source-backed research/method → matched product concept.
Include educator and beginner entry points, unified search and a batch mass scaler.
Use structured content with stable identifiers, source links and evidence status.
Clearly label demonstration catalog items and target prices; no live checkout yet.

## Suggested implementation sequence

1. Choose runtime and hosting based on the existing GitHub deployment workflow.
2. Define typed material, grade, product, paper, formulation and test entities.
3. Establish typography, spacing, neutral colors and one accent.
4. Implement the homepage and linked content/detail templates.
5. Add search and mass scaling with explicit units and calculation basis.
6. Review desktop/mobile UX, keyboard access, evidence labels and link integrity.
7. Record verified build commands and remaining gaps in HANDOFF.md.

## Prototype acceptance

- Navigation works on desktop and mobile without dead-end primary actions.
- One material links to its grades, methods, sources and product concepts.
- Literature-reported, internally reproduced and independently tested are distinct.
- Products show exact proposed sizes, included/required equipment and availability status.
- Search returns relevant content across supported entity types.
- Batch scaling preserves mass proportions, rejects invalid inputs and explains units.
- No invented performance results, testimonials, expert availability or purchasable stock.

## Production milestones after prototype

Qualified and costed catalog; safety/transport review; finalized name/domain;
expert availability; editorial review; commerce/provider eligibility; payment,
inventory, shipping and tax integration; transactional QA; private pilot; public launch.
The larger public MVP content counts remain in KICKOFF.md.

## Open choices

Name/domain, launch geography, catalog qualification, commerce provider, technical
stack and hosting. Prototype decisions must remain reversible and documented.
