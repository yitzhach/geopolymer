## 7. Website architecture

Primary navigation: Learn | Materials | Mixes | Research | Shop | Tools | Ask an Expert. Prominent search and cart; educator landing page linked from Learn, Shop and homepage. Test is embedded in every method through protocols and recording sheets; Share becomes a community area later.

| Area | Pages |
|---|---|
| Home | Starter routes, featured kits, worked experiment, evidence standards |
| Learn | Start here, fundamentals, safety, mixing/curing, testing, troubleshooting, educators, glossary |
| Materials | Material index, families, material pages, grade comparison |
| Mixes | Filterable library, method detail, batch scaling, validation status |
| Research | Search/filter, paper summaries, source methodology and corrections |
| Shop | Kits, classroom packs, precursors, activators, fillers/fibers/additives, samples, product detail, cart, checkout |
| Tools | Batch scaler, later solution and ratio tools, calculation documentation |
| Ask an Expert | Specialties, profiles, intake, scoped services and booking |
| Support / company | About, contact, SDS/TDS, shipping, returns, privacy, terms, accessibility, order support |
| Later | Account projects, saved formulations, courses, membership, community, B2B sourcing |

Key journeys: educator → lesson → class size → kit/refill; maker → desired experiment → kit → method; researcher → paper → exact grade/method → sample; professional → application → evidence → scoped expert help.

Homepage recommendation: plain-language promise, primary “Shop starter kits,” secondary “Explore materials”; then routes for classroom, first experiment and technical development. Show real specimens and an example connecting paper → mix → product. Use white/mineral-gray surfaces, charcoal type, one restrained blue/green accent, precise tables and real laboratory photography. Scientific without visual clutter.

## 9. MVP sequence and later architecture decisions

Preserve owner's public MVP counts. RECOMMENDATION: use a smaller private pilot first (3 kit types plus refill, 6–8 qualified raw products, 8 material pages, 5 methods, 10 paper summaries and 8 guides). Expand toward public MVP after testing content and fulfillment. This staging proposal does not replace the owner's scope without acceptance.

Tools: first batch mass scaler with explicit units and inputs; next grade comparison and cost-per-batch; then activator solids/water and oxide/molar ratios after expert verification. Keep atomic ratios separate from oxide ratios and mass ratios. Do not derive reactive composition from bulk chemistry without stating assumptions. Predictive formulation assistance comes last.

Technical architecture remains undecided: evaluate a hosted commerce backend with structured editorial content versus a fully integrated custom frontend. Prefer established checkout, inventory and tax/shipping services. Confirm chemical-product and payment-provider eligibility before platform selection. No software stack selected or implemented.

Phase 3 readiness: approved brand, audience/fulfillment scope, costed qualified SKUs, shipping requirements, content model and templates, sitemap/wireframes, evidence workflow and technical platform decision. Then implement catalog/content → cross-links/search → cart/checkout → tools/consulting → accessibility and transactional testing → pilot → public release.
